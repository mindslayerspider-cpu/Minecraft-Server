# Red Scythe Minecraft-Style Cinematic

Original Blender scene generator for a Minecraft-inspired red scythe weapon showcase.

## What it creates
- 1920x1080, 60 FPS, 10-second timeline
- Blocky original red scythe
- Red emissive blade accents and energy trail
- Red ember particles
- Dark environment, fog/glow-style compositor, dramatic lighting
- Cinematic camera pullback and swing tracking
- Final hero pose with subtle impact shake
- Hold at the end for a title/username overlay

## How to use
1. Install Blender 3.x or 4.x.
2. Open `red_scythe_intro.py` in Blender's Scripting workspace.
3. Run the script.
4. The scene is generated automatically.
5. Render the animation to create `red_scythe_intro.mp4`.

This is an original Minecraft-inspired design and does not copy a specific creator's asset or branding.
